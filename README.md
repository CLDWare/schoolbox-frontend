### Setup
```bash
deno install
```
Om frontend te gebruiken moet je de backend ook hebben, maar dat is niet mijn probleem om docs over te schrijven

### Dev
```bash
deno run dev

caddy start
```
Hierna kan je [localhost:8000](http://localhost:8000) bezoeken
